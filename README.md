Two lines explaining rain to a 10-year-old: the sky tipping over a bathtub it forgot was full — and an honest second line about what that analogy maps and what it leaves out. Written for make.fun's "Everyday Things, Two Lines, Longer Run" bounty. The program writes the two lines to `entry.txt` in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
